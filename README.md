# Curso Python com Django — Instituto Federal de Brasília (IFB)

Este repositório contém os projetos práticos e códigos desenvolvidos como parte do curso Desenvolvimento de Software com Formação BackEnd - Python com Django, oferecido pelo Instituto Federal de Brasília (IFB).

O material presente aqui vai além das atividades de sala de aula, incluindo anotações de estudo detalhadas, resumos de conteúdo e exercícios complementares elaborados para consolidar o aprendizado e garantir um domínio prático e aprofundado dos temas.

## Conteúdo abordado

- **Variáveis** — tipos de dados e atribuição
- **Operadores** — aritméticos, lógicos e de comparação
- **Estruturas condicionais** — `if`, `elif`, `else`
- **Laços de repetição (loop)** — `for` e `while`
- **Coleções** — listas, tuplas, dicionários e sets
- **Funções** — definição, parâmetros e retorno
- **POO** — Programação Orientada a Objetos (classes, herança, encapsulamento)

## Como rodar

Cada pasta contém exercícios e scripts Python independentes. Para executar um arquivo:

```bash
python nome_do_arquivo.py
```

Este repositório contém os projetos práticos e códigos desenvolvidos como parte do curso Desenvolvimento de Software com Formação BackEnd - Python com Django, oferecido pelo Instituto Federal de Brasília (IFB).

O material presente aqui vai além das atividades de sala de aula, incluindo anotações de estudo detalhadas, resumos de conteúdo e exercícios complementares que foram elaborados para consolidar o aprendizado e garantir um domínio prático e aprofundado dos temas.
